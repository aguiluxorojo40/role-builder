# Layer 2 de SMW — fondos y 2ª capa de objetos (extraído de la ROM)

Por cada nivel de MAPA, su Layer 2. **Fondo** = tilemap comprimido en banco $0C
(864 bloques Map16, tabla Map16 de fondo $0D:9100); **objetos** = 2ª capa de
objetos con puntero de 24 bits (misma estructura que Layer 1). Clasificación:
banco 0xFF ⇒ fondo (regla de `add_packed_level_bg` de snesrev/smw).

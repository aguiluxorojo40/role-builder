El corazón · lienzo primero

Pinta un nivel con el pulgar.

El lienzo manda; las herramientas viven en un menú radial (el botón ámbar, abajo a la derecha), igual que en la app. Elige una tesela, pinta, define un sello y estámpalo para construir rápido. Esto es el prototipo jugable del flujo.

Tesela del pincel

Paleta del nivel — palette-swap en vivo

Como en SNES: el mismo nivel cambia de ambiente al cambiar la paleta, sin repintar un solo tile. Esto ya se alimenta de las paletas reales de la ROM.

Sellos — tu biblioteca de piezas

Con Sello activo: arrastra un recuadro sobre el nivel para capturar una zona. Queda “en mano” y se estampa donde toques.

Cómo se prueba

  1. Abre el menú radial (botón ámbar) y elige una herramienta.
  2. Pincel: elige tesela arriba y arrastra sobre el nivel.
  3. Moneda / Enemigo: toca para colocar marcadores.
  4. Sello: arrastra para capturar → toca para estampar.
  5. Borrar: limpia tesela y marcadores de la casilla.
El botón ámbar abre el menú radial, como en la app.
El alcance real · lo que el motor debe exponer

Arquitectura de la experiencia

Ordenado significa: cinco lugares, no cincuenta botones.

La complejidad de un editor de ROM se esconde tras un mapa simple. Cada zona hace una cosa; el lienzo es siempre el centro y las herramientas aparecen bajo el pulgar.

De la idea al código real

Primero que funcione la idea. Luego, al motor de verdad.

Este prototipo web valida la UX sin coste. Cuando el flujo convence, se lleva al Compose real del repo — con la lógica en core, verificada por CI, y una APK nueva.

Fase A · ahora

Prototipo de UX

Este plano: lienzo, radial, sellos y el mapa completo de sistemas. Iteramos rápido en HTML.

Fase B

Ingesta de assets SMW

Leer teselas, sprites, paletas y fondos de SMW y volcarlos al formato de proyecto JSON+PNG.

Fase C

Editor Compose

El flujo aprobado, portado a la app Android real. Lógica en core, probada con tests JVM.

Fase D

Publicar

Exportar tu creación como juego independiente (APK) o como nivel/hack de SMW.
